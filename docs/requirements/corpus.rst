.. Corpus requirements

Golden Corpus
=============

.. req:: Match Python on every corpus case
    :id: HMD_META_TYPES_REQ_CORPUS_001
    :status: implemented

    For every case in ``testdata/corpus/cases.json``, Go shall reject the input
    with the category in ``golden/<case>.error``, or serialize it to exactly the
    bytes of ``golden/<case>.json``, and read its own output back to the same
    bytes. This is NERD005 SPEC005's exit criterion for phase 2.

.. req:: Python reads Go's output back unchanged
    :id: HMD_META_TYPES_REQ_CORPUS_002
    :status: implemented
    :tags: trace-exempt

    Python shall deserialize every Go output and serialize it to its own golden
    bytes. Verified by ``make docker-corpus-roundtrip``, which writes Go's outputs
    and runs ``tools/corpus/golden.py --check`` against them in a Python
    container; reqtrace cannot see that Python step.

.. req:: Generated go_lib code round-trips the corpus
    :id: HMD_META_TYPES_REQ_CORPUS_003
    :status: implemented

    Code generated by hmd-tmpl-vocabgen's ``go_lib`` template from the corpus
    schemas shall compile against this module, embed each ``.hms`` with its
    attribute order, pass the corpus, and expose typed accessors that serialize
    as Python does. The committed output in ``internal/corpus`` shall match the
    corpus schemas.
